# Home-Court-Advantage
### Small data analytics project answering three questions regarding home court advantage.

Question
Has home-court advantage in the NBA declined since 2000, and what happens to it when fans are removed?

This is a three-parter:

1. Does home-court advantage exist, and how big is it?
That is, if the home team wins more than 50\% of games and outscores opponents on average, the advantage is valid \& exists.

2. Has it declined?
Fitting trend line thru 25 seasons of games. Negative slope --> decline is real

3. What happens without fans?
Looking at the 2020 bubble with more recent normal seasons.
